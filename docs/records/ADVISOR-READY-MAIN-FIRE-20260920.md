# 型の認定と本線5連鎖の発火判断を分離

実施日：2026-09-20。
Habiticaタスク：`b854b90a-d45d-4578-ac96-accc826812fb`。
タスク名：「GTR：連鎖尾の型が未認定でも安全な本線5連鎖の発火を優先する」。

## 対応範囲

[失敗分析の項目1／A](../research/ADVISOR-FAILURE-PATTERNS-20260920.md)への対応。
Y字・L字・座布団を目指す構築方針と、その完成認定は維持する。
完成した本線が実際に5連鎖以上するなら、教材の形として未認定でも発火を優先する。

以前は `isAdaptiveTailComplete` が発火の終端優先度にも必要だった。
この条件を現在手の発火優先判定から外した。構築中の骨格探索は従来どおり型の完成を目標にする。
実際の組ぷよでの次の検証は残している。

- 標準発火口へ正しい色を置く合法な配置であること。
- 基準本線が5連鎖以上であり、相方を含む実際の連鎖も基準以上になること。
- 基準の各段で消える元のぷよが、同じ段ですべて消えること。
- 発火後に出現位置を塞がないこと。骨格探索内にも明示的な確認を追加。
- 本線とは独立した副次消去を区別すること。通常発火を副次消去付き発火より優先する既存の差は維持。

教材の完成条件、ツモ供給、骨格の構築点、Y字優先、折り返し優先、未知ツモを見ない制約は変更していない。
発火点伸ばしや移動した発火口の認定は今回の対象外。

## 回帰テスト

失敗分析で確認した14ゲーム・30局面を元レポートのSHA-256付きで固定した。
[局面データ](../../src/game/advisor/fixtures/unrecognized-tail-fires.json)と
[テスト](../../src/game/advisor/PlacementAdvisorUnrecognizedTailFire.test.ts)を追加。

- 30局面×4通りの色名入れ替え：型が未認定のまま、本線5連鎖以上を優先して実発火する。
- 色計画が指定されていなくても、成立した本線を発火する。
- NEXTに発火色があっても、現在手の実発火とは扱わない。
- gameIndex651：単ぷよなら5連鎖でも、相方が末尾色を先に消して4連鎖に縮む場合は除外。色替え4通り。
- gameIndex43：4連鎖に5連鎖用の終端優先度を付けない。
- 入力盤面・組ぷよ・色計画を変更しない。

変更前は当初追加した128件のうち121件が失敗、7件が成功。
さらに下記の不採用案で問題が出た4局面×4通りの色替えを追加し、型の構築が維持されることを検証する。
最終版は追加144件を含む全364件・26ファイルが成功。型検査・製品ビルドも成功。
ビルドの既存の大きなチャンク警告は残る。

### 手順と副作用

配置手順が変わったのは15ゲーム。すべて変更前と同じ盤面・同じ手順をたどり、
最初の差分で副次消去のない本線5連鎖以上を発火した。構築途中の寄り道は増やしていない。

- gameIndex71：6列へ積み続けて未発火だった局面から、15手目に1列で5連鎖。残り2個。
- gameIndex950・995：それぞれ19手目・16手目に6連鎖を回収。
- 既に5連鎖を打てていた959：18手目→14手目へ早まり、残り8→6個。
- 先読み緩和案で崩れた301・620・726・930は、元の完成手数・発火手数・残り個数へ戻った。
- 相方が連鎖を壊す651の見送りと、元の意図しない消去3局は変更なし。

同じ発火済み789局だけで比べると、残り個数は8.614702→8.612167。
改善1局（959）、悪化0局、同等788局。全803局の平均改善には新たな発火局の構成変化も含まれる。
2・3列に限った残りは、同じ789局では3.139417→3.141952と合計2個増加した。
全発火局平均は3.139417→3.122042だが、これだけで「2・3列の捨てぷよ改善」とは判断しない。

ちぎりは4,636/16,936手→4,629/16,890手、段差合計10,466→10,458。
総回数は減ったが、100手あたり頻度は27.3736→27.4067とわずかに上がる。
完成した本線を打って以後の手順が短縮された影響があるため、操作の自然さが改善したとは断定しない。

H1（構築順）・H3（型の継続）はこの標本と既存回帰で同等。
H2（両ぷよの活用）は全体の余りが微減する一方、同条件の2・3列の残りは微増。
H4（ちぎり・高さ）は回数と頻度を併記し、改善宣言はしない。
H5（発火点伸ばし）は未実装のまま。H6は発火優先の判断を説明できるが、全候補の説明UIは未実装。

### 先読みまで緩めた案は不採用

最初の案では骨格探索内の発火からも型の認定条件を外した。
[この案の1,000ゲーム](../../benchmarks/results/ready-main-fire-20260920-after.json)は、
5連鎖773→788、連鎖尾939→935だった。副次消去は3のまま、ゲームオーバー0。
gameIndex301・620・726・930で、現在手は発火できないのに、型を仕上げない将来の発火ルートへ構築を変えた。
特に620・726は以前と同じ手数で5連鎖するのに、型を作らず余りも3→4個、10→14個へ増えた。
この4件の型認定低下を許容して採用せず、先読みの型条件を戻した。
残す変更は「現在手ですでに打てる本線の見逃し防止」と発火後の出現位置確認だけ。
不採用案の固定コードは `ready-main-fire-20260920-code.js`、SHA-256は
`63278a7296df7d19d23885130b271eaf70cb387fe8155fcd6c096215f469254a`。

## 評価の限界と残る課題

- 今回の1,000ゲームは失敗分析で閲覧済みの固定回帰集合。未知の別seedへの成功率保証ではない。
- 人間の101記録・最大12手の比較は序盤の回帰確認であり、後半の発火や多重の自然さを保証しない。
- 「型の認定を増やす」変更ではない。未認定の本線を打てても、連鎖尾完成へ水増ししない。
- 折り返しへの必要色の配分、5連鎖成立までの停滞、発火色待ちと相方の置き場は別課題として残る。
- 相方で壊れる連鎖や、別の場所で起きる5連鎖を本線として認める修正ではない。
