# 土台100点と全盤面状態の分離

利用者が承認した「土台19個＋範囲外の相方」で満点になりうる設計を実装。
旧「全盤面19個」は非発火・2個組の空盤面開始では到達不能だった。

本書は採点修正時点の記録。後続の[推薦改善](ADVISOR-PERFECT-FOUNDATION-20260925.md)では、
採点を変えずに固定500ゲームの100点到達が0→6件となった。以下の当時の数値は更新せず残す。

## 変更

- 範囲外を消去・重力より先に除き、満点の個数・低さもその土台だけで判定。
  5連鎖・余り0・下3段18個＋右端4段目1個の条件は維持。
- 基本形2＋尾3は実シミュレーターの元セルの消去順を確認する内訳。連鎖数を水増ししない。
- 結果画面を「土台スコア」にし、範囲外個数・全盤面接続見込み・閉塞等は別表示。
  見込みは仮置き1〜2個の限定探索。接続未確認を不成立の証明とせず、上部すべてを有効ともみなさない。
- ガイドの配置順位・供給・物理・手数上限は変更しない。土台100点を全盤面の安全判定に使わない。

## 検証方針と実装テスト

元の3理想形と4色替え、範囲外の色変更・追加・除去に対する採点不変性、
範囲内の必要セル欠損・余計な1個の減点、基本形の同時消しを2と数えない例を確認。
10組の実配置で20個を消去せず積み、19個の土台＋範囲外1個で100点に到達する再現手順を追加した。
これは作成した回帰用手順であり、random500のガイド成功件数へは加算しない。
土台100点でも全盤面の接続未確認・出現位置閉塞となるケースと結果画面の表示を確認する。
