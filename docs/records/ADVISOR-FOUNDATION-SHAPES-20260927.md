# 右端に限定しない満点土台へのガイド推薦

2026-09-27。Astra設計v1、Sol実装。前回の[採点と一覧の見直し](../design/GTR-SURFACE-QUALITY-20260927.md)に続く推薦変更。

## 対象と保護条件

右端が高い形だけへの補助点と満点候補制限を外す。GTR完成を最優先にし、同程度の完成・回収・操作条件なら後続の足場を比較する。
平らなら無条件に良いとはせず、5列目が高い形も右端の高い形も合法な選択肢にする。
採点版 `masked-foundation-minimal-v2`、評価範囲、一覧30形、物理、4色供給、非発火方針は変更しない。
推薦が読むのはCURRENT/NEXT/NEXT2だけ。仮想接続例を実際の達成として集計しない。

## 変更契約

1. `FoundationPreference` の土台内5連鎖以上に対する2000点は維持し、`rightEdgeRaised` による追加100だけを撤廃する。
   低さ・平坦さの別の数値加点には置き換えない。旧診断の意味と保存互換は維持する。
2. `PerfectFoundationPlanner` は既存52骨格から4段以下・6列の候補を取り、右端1セル・下3段全埋めの制限を外す。
   配色は共通採点器で100点かつ事前消去なしを再検証する。独自の満点定義を作らない。
3. Y字3の消去元セルを抽象化した `....DE / ABC.ED / AABCCD / BBCEED` を満点探索専用に1例追加する。
   汎用骨格やギャラリーを変更せず、advisorからguide/UIをimportしない。
   Y字8の `....E. / ABCEDE / AABCCD / BBCEDD` は既存骨格に含まれる。
4. 基本形完成後・範囲内13〜18個・最大3組の実配置探索を維持。各段24配置で、剪定なしでも最大14,424配置試行。
   許可root、非消去、閉塞回避、色整合、終端100点・尾完成・本線接続・仮発火後の実在余り5個以下を維持する。
   既に今完成できる場合は、その初手以外へ満点経路で逸らさない。完成後の満点固定は復活させない。
5. rootごとに最初の成功で同一深さの探索を止めず、その深さの成功経路を比較する。成功したrootの次の深さ以降は省略する。
   同じroot・同じ到達盤面は累積ちぎりコストが小さい経路を残す。
6. 経路は完成手数、全盤面接続の実在余り、累積ちぎり、既存surfaceShapeCost、最大列高、3〜6列の最大隣接段差、同段差合計の順で比較する。
   足場は実ツモで到達した終端盤面で測る。左端の発火口を埋める報酬は作らない。
   完全同等なら0を返す比較関数を使い、ContinuousAdvisorの元の推薦順位を安定整列で維持する。

## 回帰例

R=赤、G=緑、B=青、Y=黄。上部は空。Astraが共通物理で確認した例で、各色置換も検証する。

| 由来 | 下4段（上から） | CURRENTと配置 | 終端 |
|---|---|---|---|
| Y字8 | `...... / RGBYRY / RRGBBR / GGBYRR` | YYを5列縦置き | 非発火100点・尾完成・接続・実在余り0 |
| Y字3 | `.....Y / RGB.YR / RRGBBR / GGBYYR` | RRを5列縦置き | 同上 |
| Y字3別受け | `....R. / RGB.YR / RRGBBR / GGBYYR` | YYを6列縦置き | 同上 |

旧満点探索は3例とも経路0。相方1個は範囲外に入り、全盤面接続で回収される。
最終推薦を一つの座標に固定せず、返された経路の実配置・接続と採点を検算する。
同じ深さの低ちぎり、同等条件の小段差、早い完成・良い回収が足場に負けない順序、許可root、3組上限、入力不変も検査する。
現在完成の見送り防止、閉塞・余り過多の拒否、完成後100点固定を外せる既存回帰は維持する。

### 自然さの限界と悪化例

各9,932配置中、ちぎり2,823→2,827、深い谷529→536、配置後最大列高の平均5.45147→5.46315。
