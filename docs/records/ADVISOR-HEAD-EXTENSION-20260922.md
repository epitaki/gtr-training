# 左端の発火点伸ばし・連鎖尾優先順の修正候補

実施日：2026-09-22。状態：作業版へ実装・検証済み、**完成率低下があるため正式採用は保留**。
70%基準を超えたことだけを理由に、総合的な改善とは判断しない。

追記：以下は最初の候補の記録。[後続の改善](ADVISOR-CONSTRUCTION-20260922.md)では
骨格・評価を見直し、同じ500ゲームで完成率を回復した。以下の当時の数値は書き換えず保存する。

## 対応した報告と範囲

青黄の組ぷよを2列目へ積むより、1列目に下から黄→青と置き、発火点伸ばしへ利用したいという報告。
対象盤面の下4行（上の9行は空）と、現在／NEXT／NEXT2は次のとおり。

```text
.Y....
BRY...
BBRY..
RRYYRG
CURRENT=BY, NEXT=GG, NEXT2=BG
```

以前は標準発火口が1列目の固定セルであり、5連鎖探索も1列目の4段以上を排除していた。
そのため、支持色を先に消して上の青を元の青へ落とす仕込みを評価できなかった。

限定形の検証を `src/game/gtr/HeadExtension.ts` にまとめ、判定・推薦・本線認定で共有した。
報告局面は1列目・下向き（黄が下、青が上）を推薦する。黄があと2個必要な仕込みであり、
現在のNEXTに黄がないことを隠したり、完成・実発火として数えたりしない。
後から黄黄を2列目へ置くと、黄→青→赤→黄の4連鎖になることを共通シミュレーターで検証した。

- 元の標準コアと尾を壊さず、最初の頭消しの後、元の本線ぷよが1段ずつ後ろへずれて消えることを照合する。
- 対応は1列目の支持色＋落下キー、2列目の同色支持。左端のキーの上に置ける相方は2個まで。
- 新しく頭を始めなくても骨格セルを進められる候補があれば、そちらを先に残す。
- あと2個必要な頭はGTR発火可能と認定しない。尾の骨格完成・頭の不足色・実発火を分離する。
- あと1個なら新しい発火口を検証できる。実際の組ぷよが不足を補い、本線を保って消した場合だけ発火へ計上する。
- ガイドには「発火点伸ばしの仕込み：黄があと2個必要」のように、不足色と個数を表示する。

一般的な多重、さらに高い頭、任意位置の発火点移動には未対応。

## なぜL字へ偏っていたか／変更候補

以前の構築点は座布団だけ150点減点、Y字だけ1点加点だったため、同程度の進捗ではL字が座布団より有利だった。
L字が対戦で優れているという動画検証に基づく優先ではなかった。

作業版は未完成骨格の構築コストを **Y=0、座布団=150、L=190** にした。
同程度ならY→座布団→Lという練習方針であり、進んだ形や確定した発火を壊す強制規則ではない。
完成骨格には形別減点を付けない。自由形の候補も、物理進捗が同じ場合にこの順序を使う。

試行したY=0／座布団=60／L=120は既存のY字報告局面の回帰を崩したため不採用。
現在の0／150／190はその回帰を通るが、下記の全体成績では低下が残る。

L字の後を右へ2段の階段状に伸ばしがちな問題は未解決。
5連鎖探索は依然3種類の固定骨格であり、色の受け入れや右端の成長余地を十分に評価していない。
L字の出現頻度を減らすことと、L字からの伸ばしを改善することを同じ成果として扱わない。
