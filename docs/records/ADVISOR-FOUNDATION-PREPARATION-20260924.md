# 土台内の連鎖と発火ツモの受けやすさ

更新日：2026-09-24。直近の「右上が上がっていない」という報告を起点とした修正・試行記録。
右上チェックの表示修正とは別に、推薦器が土台の評価範囲を考慮する条件を追加した。
**中央の高積み・右端が低い構築の解消は未完了**。以下の部分的な改善と混同しない。

## 再現した問題

報告日時 `2026-09-24T01:28:16.629Z`、15手目、列高 `3,5,5,8,4,3`。
保存済み14手を共通シミュレーターで再生し、報告盤面との完全一致を確認した。
全盤面では5連鎖だが、土台の範囲内だけでは4連鎖・余り5個・76点。
右端の4段目は空で、右上の段差は成立していない。

従来の先読み準備評価は、全盤面での本線と発火後の余りを主に比較していた。
同じ物理5連鎖でも、上側のぷよに依存する形と、土台内で5連鎖になる形を区別していなかった。

## 変更した推薦条件

`src/game/advisor/FoundationPreference.ts` を追加し、`PlacementAdvisor` の先読み準備評価から使用する。

1. 既に連鎖尾がつながっており、見えている最大3組を実際に置いた到達盤面だけが対象。
2. 全盤面で本線5連鎖以上が物理的に成立することを従来どおり確認する。
3. 発火色と相方4色の組を着地・消去まで計算し、それぞれに本線を壊さず独立した副次消去も起こさない置き方がある場合だけ、新しい加点を許す。
4. 範囲外を除いた土台の連鎖数に、最大5連鎖まで1連鎖あたり200の内部加点。
   土台5連鎖以上かつ有効な右上の段差があれば100を追加する。
5. 打てるCURRENTの本線発火、見えているツモによる実発火、現在手の危険な高積み回避は、この準備加点より優先する。

これは推薦器内部の比較値であり、ゲーム画面の100点満点の採点を変更するものではない。
相方の試験は色の受け口の検査であり、そのツモが将来到着するという予測や実発火成功には数えない。
新しいNEXTが見えて再探索すれば、最初の先読み経路と実際の経路が変わることはある。
先読み内の全中間盤面や、任意の発火点伸ばしの柔軟性を保証するものでもない。

初手・2手目の規則、物理シミュレーター、満点条件は変更していない。

## 追加した測定

- `src/benchmark/FoundationQuality.ts`：各ゲームで実在した確定盤面を現在の採点器で評価。
  土台内5連鎖、右上の段差、両者の同時成立、100点到達を各1回まで集計する。
- `scripts/analysis/compare-foundation-quality.ts`：同条件・同seedの保存手順を物理検証し、前後を同じ採点器で比較する。
- `scripts/analysis/trace-foundation-feedback.ts`：初手からの報告履歴を検証し、同じツモで旧版・新版を実行し直す。

到達率の分母は未発火も含む全ゲーム。実5連鎖成功局内の100点率は別で、分母0はnull。
保存結果の再採点と新しいシミュレーションを区別し、元の結果・凍結コードを上書きしない。
現在の満点条件は全盤面19個のままで、相方1個を除外する見直しは未実装。

## 報告例で残る制約

候補7で空盤面から同じ15手を再実行した結果は、報告例については変更前と同じ。
15手目の本線実5連鎖・余り6個を維持する一方、土台内は4連鎖、最大列高8、右上の段差なし。
12手目の上下を反転すると土台内5連鎖になる別案はあるが、相方4色すべてを受けられず、今回は強制しない。
この報告例の中央の塔を解消したとは扱わない。

次の課題は、発火待ちに入る前の骨格・支持色の選択を改善し、上側に依存せず右上を残す経路を増やすこと。
高さの減点だけを強めたり、右上型だけに候補を絞ったりする案は上表の失敗を再発させる。
