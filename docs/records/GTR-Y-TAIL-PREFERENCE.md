# Y字を組み始めの優先形にする調整

更新日: 2026-09-19

追記（2026-09-22）：以下は当時の調整・測定記録を保存したもの。
現在の作業版は利用者の「Y字→座布団→L字」の方針に合わせ、未完成骨格の構築コストを
Y=0、座布団=80、L=90とし、有効セル1個分より小さくした。
150／190の最初の候補で落ちた完成率は、骨格拡張・完成評価も併用して回復した。
[後続の500ゲームの比較と未解決点](ADVISOR-CONSTRUCTION-20260922.md)を参照。

この文書は連鎖尾の優先調整と、その時点の測定記録。
現在の採否基準は[品質・人間らしい手順の評価基準](../specs/GTR-QUALITY-CRITERIA.md)を参照する。
H3（組みやすさ・継続性）を重視し、Y字の比率だけでなく、既に育った別形を無駄に壊さないかも評価する。

## フィードバックの再現

報告日時 `2026-09-18T18:54:00.271Z`、13手目、CURRENT青黄 / NEXT赤青 / NEXT2青緑。
「座布団は横3個を必要とするので、Y字を優先してほしい」という指摘。

保存された12手を共通シミュレーターで空盤面から再生し、報告盤面と一致した。
記録された配置はプレイヤーの操作であるため、すべてを推薦どおりと仮定せず、
各手で当時見えていた3組を使って現行の推薦を別途確認した。

- 変更前は5手目の青黄を3列目・青下に置き、3列目最下段の黄色と上側の青が異色となる。
  この配置で黄色のY字/L字候補が消え、青の座布団だけが残る。
- 13手目の6列目・青下は、すでに7/8セルある座布団を完成させる配置。
  次の赤青を1列目・青下に置けば実際に5連鎖する。ここでY字へ作り直す必要はない。

## 方針と資料の扱い

「Y字が常に最強」というゲーム理論上の断定ではなく、利用者が希望する練習方針を評価に反映する。
SAKI氏は、平らになりやすいL字・Y字を初心者が練習する形として挙げている。
一方、ツモ次第で手順を変えることも説明しており、形の強制とはしない。
[SAKI「3手問題Part.1」](https://puyo-camp.jp/posts/112283)

wata氏の403形の調査は、右側4列・下4段・4連結という限定条件ではY字の派生が最多だったという結果。
完成率や組みやすさ全般、座布団との普遍的な優劣を証明するものではない。
[wata「GTRの後ろの形のパターン数と良型について」](https://puyo-camp.jp/posts/158147)

## 実装の範囲

`FiveChainPlanner` の未完成座布団骨格には150点の構築コストを引く。
Y字には1点だけ加え、L字とほぼ同点ならY字を選びやすくする。
進捗セル1個100点に対して1組分未満の差で、完成点1000や実発火の終端点10000を上回らない。
不足色、余剰ぷよ、高さ、見えているツモの進み方と合わせて比較する。
最初の2手の折り返し優先条件、3種類の19個骨格、探索幅32、先読み最大3組、
盤面判定、連鎖尾完成・5連鎖成功の定義は変更しない。

- Y字に適合しない配置に加点しない。L字・座布団も候補として残す。
- 骨格完成後はこれらの形別調整をしない。完成済み5連鎖の実発火優先は維持する。
- `TailPlanner` の候補検出や、骨格に適合しない自由形の汎用評価には固定倍率を追加しない。
- Y字への一律加点60では今回の5手目が変わらなかった。
  一律加点150では報告局面は改善したが、別seed120回でY字96・L字11・座布団4に偏り、
  連鎖尾完成は116→111、5連鎖は98→92となったため不採用。
  その結果は `benchmarks/results/y-preference-20260919-secondary.json` に残す。
  この方式の500回測定と、座布団減点のみの120回予備測定は途中で中止し、完走結果として扱わない。
- 座布団との比較を主に調整し、Y字とL字の差は1点までに抑えた方式で最終測定する。
  seed・ツモ生成・成功条件は全方式で変更していない。

## 報告ツモ列での変化

変更後のガイドで空盤面から再実行すると、5手目は青を2列目、黄色を3列目へ横置きする。
黄色をY字の上側に置き、6・7手目の緑黄を4・5列目へ緑下で置いて7手目にY字完成。
14手目の赤青で実5連鎖を確認した。推薦へ渡す情報は常にCURRENT/NEXT/NEXT2のみ。

一方、報告された13手目の盤面そのものから再開すると、6列目・青下を維持し、
座布団完成→次のツモで5連鎖という短い手順を維持する。

回帰テストには5手目の分岐と13手目の完成直前の各4配色入れ替え、
空盤面から14手目までの再実行を追加した（計9ケース）。

## 比較測定

各ゲーム最大20手、random、初手6分類を均等に割り当てる。変更前は
`opening-20260919-final.json`（500回）と `opening-20260919-final-secondary.json`（120回）。
ツモ列を変更せず比較し、完成率の分母は失敗も含む全ゲームとする。

| 対象 | 連鎖尾完成 | 本線5連鎖以上の実発火 | 不意消し / ゲームオーバー |
|---|---:|---:|---:|
| 同一seed500回・変更前 | 472/500（94.4%） | 387/500（77.4%） | 1 / 0 |
| 同一seed500回・変更後 | 471/500（94.2%） | 391/500（78.2%） | 0 / 0 |
| 別seed120回・変更前 | 116/120（96.7%） | 98/120（81.7%） | 0 / 0 |
| 別seed120回・変更後 | 114/120（95.0%） | 96/120（80.0%） | 0 / 0 |

500回はseed20260904、結果は `benchmarks/results/tail-preference-20260919-final.json`。
最初の完成時に検出された形は、Y字120→297、L字284→163、座布団68→11、未完成28→29。
全500ゲームを分母としたY字完成は24.0%→59.4%、座布団完成は13.6%→2.2%。
連鎖尾完成率は0.2ポイント低下、5連鎖率は0.8ポイント上昇した。
5連鎖へ改善したゲームは16件、逆に到達しなくなったゲームは12件で、全局面での改善ではない。

別seedは20260918、結果は `benchmarks/results/tail-preference-20260919-final-secondary.json`。
最初の完成時に検出された形は、Y字36→77、L字61→34、座布団19→3、未完成4→6。
Y字へ寄せる代わりに、完成率・5連鎖率は各2ゲーム（1.7ポイント）減少した。
5連鎖へ改善したゲームIDは8,18,27,57、逆に5連鎖へ到達しなくなったIDは12,30,32,50,73,83。
この条件で常に成功率まで向上する変更とは評価しない。

両測定で、連鎖尾完成・5連鎖以上の各70%という従来基準は維持した。
これは指定のrandom条件、20手上限での結果であり、別の配色・悪条件モード・対人戦での保証ではない。

```sh
bun scripts/benchmark/benchmark-advisor.ts run --games 120 --turns 20 --modes random --seed 20260918 --no-output
```
