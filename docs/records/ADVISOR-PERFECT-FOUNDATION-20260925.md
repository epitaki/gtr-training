# 右端の段差を備えた低い土台への推薦改善

## 着手時点と固定条件

2026-09-25。前回の採点修正と今回の推薦改善を分離する。
前回は通常の2個組で土台100点が可能になったが、固定500ゲームの100点は0件。
土台内5連鎖375/500、尾完成479/500。19個・5連鎖・余りなしは9件あるが右端の段差がない。
比較元は `benchmarks/results/foundation-score-20260924-main500.json`。

採点条件・評価範囲・4色供給・seed 20260904・初手分類順・最大20手・非発火の停止条件は変えない。
既知500ゲームは開発・回帰集合として扱い、未知集合の汎化性能とは呼ばない。

## 仮説と実装方針

完成前のガイドは実発火を優先する旧推薦の順位を引き継ぐ。そのため、非発火で積む目的と、
19個・下3段＋右端4段目1個の完成目的を直接比較していない。

最初の改善は限定的にする。

1. 折り返し完成後、既存の低い骨格から、同じ採点器で100点になる配色だけを候補にする。
2. CURRENT/NEXT/NEXT2を実際の2個組のまま置き、最大3手で完成する経路のみ比較する。
3. 各手の早消し・出現位置閉塞・土台内の余計な上積みを除外する。
4. 終端は実配置で100点かつ全盤面から本線へ接続できる見込み・連鎖尾完成を確認する。
   その仮置き発火でも余り6個以上なら、満点のための優先経路にしない。
   この5個の上限は候補選択の保守的な条件であり、実発火後の平均余り5個以下を達成したという意味ではない。
5. 今のツモで土台5を完成できる場合、それを見送る経路は優先しない。
6. 経路がない場合は従来推薦に戻す。初手・未完成の折り返し・従来の実発火エンジンは変更しない。
7. 土台100点への到達後も、点数を固定するより本線接続・余剰回収を優先する従来の伸ばしを使う。
   下から4段目を伸ばしに使って100点未満になっても、土台5を維持していれば許容する。

理想図や仮置きの接続見込みを100点達成として集計しない。推薦の後に実際に置かれた盤面のみを数える。
右端への単純な高さボーナス、既知のゲーム番号による特例、未来ツモへのアクセスは加えない。
経路は既存骨格に整合するものに限定され、全形状を網羅しない。
根ごとに最短段数で最初に見つかった適格な経路を保持し、その中で仮想発火後の残数・ちぎりを比較する。
全経路の余り最小を保証する探索ではなく、毎手見えている組だけで再計画する。
画面には専用の案内を表示し、経路確認を完成済み表示や以前の無関係な骨格図へ置き換えない。

## 採否と人間らしさ

同条件で土台5・尾完成を維持または改善し、100点率と安全性を別に確認する。
個々の成功・失敗の入れ替わりは許容されるが、獲得・喪失・手詰まり・悪化例を記録する。
H1は折り返し完成後だけに限定、H2/H4は低い完成と相方の置き先、H3は進行中の接続と骨格の継続、
H5は本線接続、H6は推薦理由を確認する。今回の限定修正で人間らしさ全般の達成とはしない。

## 試作の結果と不採用理由

旧500ゲーム全局面の反実仮想調査では7ゲーム・9局面に3手以内の経路があった。
調査記録は `benchmarks/results/perfect-route-audit-20260925-v2.json`。
これはガイドの成功実績ではない。該当7ゲームの先行再実行では全件100点・土台5・尾完成を確認。
採点基準を緩めて100点を増やす変更ではない。

試作v1では先行ゲーム1が土台100点でも尾完成未認定となったため、終端の尾完成確認を追加。
試作では満点後の上積みによる土台点低下・ゲーム51の手詰まりも出たため、完成後の100点維持を追加した。
v2の先行7件は20手まで継続した。ただし、全ゲームの継続性保証ではない。

v2の全500ゲーム実行は100点0→7件、土台5は375件・尾479件を維持、消去/土台喪失0、推薦なし11件を維持。
ちぎり2,818→2,807、高い谷514→506だが、配置ごとの平均最大列高は5.406953→5.428457へ悪化した。
記録は `perfect-guide-20260925-v2-main500.json` と `perfect-guide-20260925-v2-comparison500.json`。

個別に調べると100点維持が左右の高積みを誘発した。game1の最終列高は
旧 `3,7,6,8,8,8` に対しv2 `13,13,3,3,3,5`。game353も2列目・6列目が13段になった。
game7の終端の仮置き接続時残数は旧1→v2 14個で、低い土台の点数を保っても上部を活用できていない。
このため **v2は不採用**。完成率と満点率だけで自然さの改善を主張しない。

v3では100点維持の優先処理を撤去。先行7ゲームの極端な高積みは減ったがgame51が途中で接続候補なしとなった。
完成時から仮置き後8個残る経路を優先した例であり、満点より余剰の回収見込みも確認すべきと判断した。
v4は仮置き後余り5個以下の候補だけを優先し、完成後の処理は元のガイドへ戻した。
旧手順上の該当経路は6ゲーム・7局面（`perfect-route-audit-20260925-v4.json`）。
v4も全500ゲームを空盤面から再実行した。旧結果の流用・成功例だけの分母にはしていない。

### 手順・悪化例・限界

- H1：初手・折り返しを完成するまでの順位は変更なし。全局の初手2手も一致。
- H2：土台内の余り0は6件増加。ただし満点時も範囲外が3〜7個ある。
  仮置きでの全盤面残数は1〜5個で、範囲外すべての有効活用や実発火の達成ではない。
- H3：変更6件は前後とも最初に完成した尾がY字。土台5の到達は遅れていないが、
  尾だけの完成はgame1で12→13手、game486で11→13手へ遅れた。他4件は同じ。
- H4：ちぎりは2手減ったが、高い谷は5手増加し、平均最大列高も微増。総合的な平坦化の達成ではない。
  特にgame449は高い谷0→6手、最大列高8→12。最終列高は `3,12,9,7,3,6` で改善余地がある。
  game486は谷1→0手だが最大列高9→11。game7は最大列高10→9、game82は12→10。
- H5：全6件の満点時に全盤面の接続見込みを確認。game1は上部の発火点から元の土台へ戻る。
  一方、game449の終端で仮置き発火した場合の残数は旧5→新8個。接続維持と回収品質は同義ではない。
- H6：右端を残す目的と、まだ完成ではないことを専用文で案内。各ぷよの役割の完全な説明は未対応。

完成率維持と満点到達の改善を確認した一方、人間らしさ全般・全ゲームの低い上積みは未達。
とくにgame449の完成後の高い谷を次の回帰対象とする。v2のような満点固定は戻さない。
