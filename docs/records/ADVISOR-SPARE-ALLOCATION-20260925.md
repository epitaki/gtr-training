# 完成前の相方を頭・尾へ配分する

日付：2026-09-25。対象は非発火ガイド `ContinuousAdvisor`。採点・供給・停止条件は変更しない。
[学習記録](../research/GTR-SPARE-ALLOCATION-RESEARCH-20260925.md)の H2・H5 を中心にした限定変更。

## 優先順位と対象

1. 基本形を塞がないこと、CURRENTで可能な土台5完成、見える3組での満点経路を優先する。
2. それ以外では従来の土台構築推薦を基準にする。
3. **配置後の評価範囲内の色と位置が完全に同じ**別案だけ、範囲外の配分を比較する。
4. 上部を含む全盤面に合法な同色1〜2個の仮発火を入れ、元の土台が同じ順番で消えることを検証する。
   範囲外を土台点へ足さず、仮発火を実発火・成功実績へ数えない。
5. 仮発火の残数が厳密に減り、本線の連鎖数と発火に必要な個数を悪化させず、本体の早消しリスクも
   増やさない場合だけ候補にする。同色が隣り合うだけ、高さを均すだけでは優先しない。
6. 既存推薦に完成可能な骨格がある場合、別案でも**同じ完成骨格**を維持できることを求める。
   現在の下側の色が同じでも、上部の落ち方が完成を壊す場合があるため。

新しい比較は現在の1組を実配置した盤面に限る。元の土台探索は引き続き CURRENT/NEXT/NEXT2 を使う。
未知の色を骨格へ埋めた完成図は接続実績にしない。完成骨格の照合は、進行中の構築を壊さないための条件。
発火口を塞ぐことそのものへ加点しない。尾側の回収がよければ入口を空けたままそちらを使う。
土台完成後の既存の横3・L字キー待ち探索は変更しない。

## 報告盤面と制限

2026-09-24T18:35:52.589Zの報告15手を物理再生すると、報告盤面と一致する。
同じ供給を空盤面から再推薦しても、v2 はこの報告の青3連結・2列目上積みを解消していない。
基本形の完成時期を遅らせず、8手目以前から複数手にまたがる配分を変える探索が必要。
今回の変更でこの報告そのものを解決したとは扱わない。

保存された別盤面 game165・11手目では、黄青を2列目へ積む代わりに、左端へ下から青→黄と置ける。
土台3連鎖は不変で、仮発火による全盤面の回収後残数は8→6個、頭1段の接続が加わる。
これは同盤面での反実仮想であり、実発火の余り平均や500ゲームの成功数ではない。
尾側の別例では、入口を空けたまま落下回収へ振り分けられる。

一般的な多重、1個目からの条件付き頭仕込み、任意の未知ツモへの受けの広さは今回の範囲外。
仮発火の残数が減っても、あらゆる将来のツモで組みやすくなる保証はない。
