# 骨格の選択肢と完成優先の改善

実施日：2026-09-22。作業版へ反映。完成率・5連鎖率は回復したが、
2・3列の残りとちぎりには悪化があり、人間らしさ全体の改善・正式採用とは区別する。
利用者がプレイで確認できる候補版として残す。

## 対象と変更

前回の[限定発火点伸ばし・形別調整](ADVISOR-HEAD-EXTENSION-20260922.md)は、
報告局面には対応した一方、連鎖尾完成94.6→92.4%、本線5連鎖78.6→76.6%と悪化した。
GTR完成を優先し、Y→座布団→Lの方針と両立させることを今回の対象にした。

1. **右側の骨格を3配置から11配置へ拡張。** 元の3配置を残し、右端が3段になる8配置を追加。
   毎回同じ低い階段に限定せず、D/Eの後続を別の順序で積める候補を増やした。
   配色ごとに暴発しないことと、標準発火から実際に5連鎖することを検証する。
   動画から転記した8例ではなく、物理検証した人工候補である。任意の多重・色受け評価ではない。
2. **見えているNEXT2まで初手候補を残す。** 同盤面の重複除去後、各初手の最良継続を1つ残し、
   残りの枠を得点順で埋める。形の好みだけで別案が早く消えることを抑える。
3. **形の好みより完成進捗を優先。** 未完成の構築コストをY=0、座布団=80、L=90へ変更。
   前回の150／190は有効セル1個の100点を上回っていた。完成済み骨格には形別減点をしない。
   現にコアと連鎖尾が接続した中間目標へ100点を付ける。単なる部分一致や仮補充を完成扱いしない。
4. **両方使えるツモを折り返しへ。** 最初の2手の優先に加え、3手目以降は2個とも折り返し不足を
   埋める場合に限り優先する。片方だけ使って相方を捨てる強制ではない。
5. **できた5連鎖の発火口を守る。** 骨格探索で、通常発火口が5連鎖を成立させている場合、
   新しい頭待ちで塞がない。既に仕込んだ頭の継続と発火、利用者の青黄報告局面は維持する。

幅32、CURRENT/NEXT/NEXT2、4色供給、20手上限、成功の定義は変更していない。
内部点数を見直したので、過去に保存した推薦スコアと現行スコアの数値は直接比較しない。
