# 深い谷を避ける推薦と、挟まれた縦ぷよの上下交換

対象：2026-09-22の利用者フィードバック。固定500ゲーム比較を完了し、限定改善として反映。

後続：[009-D](ADVISOR-TALL-WELLS-20260922.md)で、先読み発火の終端でもCURRENTの高い谷を比較する限定改善を採用。
以下は初回修正の記録であり、現行の終端比較・1,500ゲーム検証は後続資料を参照。

列の高さは `[3,7,3,7,0,6]`。3列目は左右より4段、5列目は左右より6段低い。
キャプチャ時の組ぷよはまだ上方にある。3列目の谷へ落ちたとき、横回転の空間がなくなる。
回転できることとは別に、このような形をなるべく作らないという追加要望を反映する。

## 操作の修正

共通の `PuyoPairManager.tryRotate` が、回転後の座標と向きをまとめて返す。
通常90度回転→従来の左右壁キックの順で試し、どちらも不可能な場合のみ、
縦ぷよの軸の左右が占有されていれば180度の上下交換を行う。
ZまたはXの1入力で実行する本アプリの操作仕様。元作品の入力猶予・連打仕様の完全再現ではない。

交換しても使う2マスは同じ。色の所属は変えず軸座標を移すので、
向き・軸色・子色とフィードバック用の配置情報が矛盾しない。
壁際、通常回転、回転不能な床、範囲外・占有セルへの進入も検証する。
ガイド付き／スコアアタックの両方で共通処理を使用し、同じフレームの落下操作後の位置から回す。

## 推薦の変更

以前の自由形スコアの高さ減点は、設置位置が上から5行以内に来たときが中心だった。
骨格探索には高い列への減点があるが、候補評価を置き換えるため自由形側の改善だけでは効かない。
さらに先読みでは過去の構築スコアが0.01倍へ減衰し、現在の積み方の違いがほとんど消える。

`BoardSurface` で現在手の設置後の高さを評価し、両経路へ追加する。
骨格探索では現在手のコストを先読み後も保持し、候補の絞り込みと最終比較に使う。
成立した本線5連鎖の発火には形状コストを持ち越さない。

- 全列が4段以下なら減点しない。低い連鎖の骨格と上部の伸ばし余地を保つ。
- 内側列の谷の深さを `min(左右の高さ) - 自分の高さ` とし、2段を超える部分の二乗を加える。
- 隣接段差の2段超の部分を加える。ただし1列目と2列目の差は除外し、発火口を埋めさせない。
- 高さ5段超の部分の二乗×4を加える。谷の片側だけを高くする逃げ方も抑える。
- 合計の上限は90。骨格進捗1セル100より小さい軟評価であり、平坦化を最優先にしない。
- 骨格への色一致、実際の連鎖検証、暴発回避、初手優先、Y→座布団→Lの方針は維持する。

最初の試行は先読み先の段差まで追加減点したため、以前の低い接続・Y字の回帰テストに失敗した。
その試行は不採用とし、現在の配置の高い積み方を評価する方式へ限定した。
現在の局面にない高い将来形を理由として、現在の低い本線接続を避けない。

## 回帰例と限界

前回の悪化例game159の11手目では、先読みの約0.000122点差で2列目へ縦積みしていた。
今回の比較では4列目の低い接続へ変わり、色替え4通りでも同じ方針になる。
報告済みの「青が下・緑が上」の低い本線参加、Y字の色順、完成した5連鎖の発火も維持する。
今回の14手目盤面では、引き続き3列目へ下から赤→緑を置き、谷を2段浅くする。

**今回の報告ツモを初手から再生しても、13手目の高さ `[3,7,3,7,0,6]` は残る。**
今回の修正だけでこの並び自体を解消できたとは扱わない。
形状減点だけで、すべての深い谷が消えるとは限らない。
色順が合わず、低い穴へ置くと骨格が壊れる場合は高い配置が残る。
固定骨格外の自由な多重や、途中ぷよ全個の用途判定を新たに実装したものではない。
