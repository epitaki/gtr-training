# GTR調査資料台帳

資料の根拠と限界を管理する台帳。現在の開発方針・合格条件は
[品質・人間らしい手順の評価基準](../specs/GTR-QUALITY-CRITERIA.md)に集約する。
初回調査、後続調査、人間の記録、盤面の物理検証を単純に足して独立した証拠の件数とはしない。

最終確認: 2026-09-04

対象: 36資料、24以上の著者・組織・プロジェクト

初手分野の追補: 2026-09-19に既存4資料を再確認し、下記3資料を追加した。
初版36資料すべてを再確認したものではない。

2026-09-27追補：[Y字3・8の段差と伸ばしの比較](../design/GTR-SURFACE-QUALITY-20260927.md)に、
ちぇすな・jemist・ぴろぷよ等の再確認とmomokenの連鎖尾動画の部分確認を整理した。
記事の原則、動画の字幕/選択場面、独自教材の物理例を区別し、資料数・試合数へ重複計上しない。
6列目最高を必須とせず、雪崩接続と折り返しから右へ伸ばす足場を別に確認する。

## 読み方

- **一次・公式**: ゲームルール、公式教材、公式競技紹介の確認に使う。
- **歴史・海外**: 用語の変遷と、日本語圏だけでは見えにくい整理を確認する。
- **講座・実戦考察**: 手順、失敗例、練習法を得る。著者の経験則であり普遍的事実とは限らない。
- **研究**: 教育設計、複数解、AI評価の限界を確認する。研究条件外へ数値を一般化しない。
- **検証ツール**: 消去順と盤面例の再現に使う。ツール自体は戦術の正しさを保証しない。

同じ主張が複数資料にあることは参考になるが、転載、翻訳、同じ著者の連載は独立した証拠として扱わない。「主な用途」は本調査で採用した範囲であり、資料全体の要約ではない。
