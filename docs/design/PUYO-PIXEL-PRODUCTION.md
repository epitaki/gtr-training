## 寸法・連結

24px→48pxの盤面、12px→36pxのNEXT、12px→24pxを26px枠中央のNEXT2、8px→16pxを18pxセル内の教材。
小サイズは専用生成原画から取得し、顔の違いを実寸で確認する。
顔ROIの切り出し・サンプリング範囲を記録し、赤の縦目、緑の横目、青の伏せ目、黄の山形／角形を保持する。
12px／8pxとも目と口を消失させず、顔の暗色配置を4色で区別する。輪郭やハイライトの差は顔の差に数えない。

4色：red/green/blue/yellow。原点は中央(0.5,0.5)、トリミング・回転なし。
未接続外周は1px透明。上1・右2・下4・左8の16接続で、接続窓は原則8〜15の8px。
向かい合う接続境界のalpha/RGBを一致させる。顔の画素位置・内容は接続マスクによって変えない。
通常と着地の足元は同じ最終不透明行に揃え、下接続が外周へ届くケースは区別する。
初回QAで連結の長い角柱が目立ったため、Astraが通常・接続胴体を22×22、left1/top1、足元22へ調整する案を採用。
顔も同じ生成画素の正規化範囲で揃える。比率が不自然になる場合は20×20、left2/top3を次案とし、48pxの縦2個・2×2で確認する。
最終alphaは0/255。半透明ガイドは表示側でalphaを与える。1色当たり8色以内を目安にする。
アトラスには各矩形の周囲2pxの透明余白を持たせる。

## 命名と動き

色ごとに以下を揃える。idle/connect0/fall0/land2が同一画像なら同一矩形参照を明記してよい。

- `red/idle`、`red/connect/0..15`、`red/connect-enter/0..15`
- `red/fall/0..1`、`red/land/0..2`、`red/clear/0..2`
- `red/mini12`、`red/mini8`、`red/particle/0..2`（粒は6px）

再生時間は現行ChainPlaybackを変えず、対応表だけを保存する。
gravityは個体の時間へfall0→1、land80msは0〜40/40〜64/64〜80、emphasis120msはclear0、fade180msは0〜60/60〜120/残り粒。
接続成立は既存段階内で初期→安定表示を重ねる設計であり、新しい物理待ち時間を追加しない。
非ゼロ15マスク×4色では成立コマと安定コマの肩に画素差を持たせ、顔と境界は変えない。マスク0は同一でよい。

接続成立の対応表（時間区間は開始を含み終了を含まない）：

| 場面 | 表示 |
|---|---|
| gravity後のland | 0〜40ms land0、40〜64ms land1。64〜80msの通常体区間で、新規接続のある個体はconnect-enter。80ms以降はconnect |
| 動かない隣接個体 | 同じlandの64〜80msで新規接続が増えた個体のみenter。既存接続は再点滅しない |
| landなしの初期emphasis | 消去対象はclear0優先。対象外の新規接続は0〜40ms enter、40ms以降stable |
| 再生段階なしの0連鎖 | 即時stable。接続成立のための待ち時間を追加しない |
| 消去・取消・盤面変更 | clearを優先。取消後や古い接続のenterを持ち越さない |

接続の新規成立は隣接する実個体の関係で判断し、移動中の個体は対象にしない。
同色の個体が入れ替わる場合を色だけで判断しない。16msのenterは既存land2区間を利用するため、すべての描画フレームでの観測を保証しない。
この表は015-C向けの素材契約で、Bでゲームの再生器は変更しない。

### 新規と既存の接続が混在する場合

通常は `connect/currentMask` を基底にする。成立時間中も、実個体関係から得た `newAdjacencyMask` の肩だけを同じcurrentMaskのenter画像からコピーする。
フレーム内の矩形 `[x,y,w,h]` は、上 `[8,2,8,1]`、右 `[21,8,1,8]`、下 `[8,21,8,1]`、左 `[2,8,1,8]`。
新規maskは現在maskの部分集合。新規0ならstable、全接続が新規なら既存enter全体を使ってよい。184フレームを維持し、Bでは対応表・静的合成QAと検査までを実装する。

右接続2から上が加わった現在3／新規1では、上肩だけ変化し、右肩はstableのままにする。
色もmaskも同じでも隣接する実個体が入れ替われば、その関係は新規になり得る。単純な現在maskと旧maskの差で新規を決めない。
全maskと新規部分集合について、指定肩以外・顔・alpha・外周境界がstableと一致することを検査する。
通常フレームのトリミングは不要だが、この成立演出には矩形の部分合成が必要。実描画の実装と確認は015-Cで行う。

## 生成結果の注意

透明背景を要求した初回生成はRGBで市松模様が描かれていたため、本番alpha素材とみなさず不採用。
背景をimagegenでマゼンタへ修正した原画を使い、承認された画像加工でalphaを作る。
magentaの混ざった輪郭が残らないよう二値化・少数色化し、顔の暗色やハイライトを削らない。
imagegenの寸法指定は実測と異なることがある。motionは1536×1024、partsは1254×1254を実測したため、実ファイル座標を記録する。
