## 2. 8bitテーマと文字の統一

### 報告とコードから確認できた不統一

- 添付の結果画面で、見出し・チェック・補足文に文字の印象や太さの差がある。
- React側はM PLUS Rounded 1c、Phaserの共通定義はSegoe UI / Noto Sans JP、MenuSceneはArialを指定している。
- Phaserの各所に10〜32pxの個別指定・bold・stroke指定があり、共通のサイズ／太さの規則が徹底されていない。
- 文字のぼけの単一原因は未確定。フォントの読込、Textの内部解像度、CSS表示倍率、DPR、座標の端数を切り分ける。
  `image-rendering: pixelated` の一括指定だけで日本語の可読性が改善するとは扱わない。

### 設計方針

日本語・英数・記号を含むピクセル系フォントの権利・収録文字を確認し、ライセンス付きでローカル同梱する方針を検討する。
役割別の文字サイズ・行間・色・縁取り・ウェイトを共通化し、意図しない代替フォント／疑似太字を避ける。
ReactとPhaserの両方に同じテーマの原則を適用し、フォント読込後に描画する。失敗時も文字欠落で操作不能にしない。
結果画面、ガイド／スコアアタック、ホーム／サイドメニュー、完成形一覧／拡大、共有／入力設定を対象にする。
枠・ボタン・背景・フォーカス表示も既存の独自ぷよドット絵に合わせる。ぷよスポの画像や書体を転載しない。
装飾より可読性を優先し、小さい補足文を無理な縮小で詰め込まない。

### 完了条件

同じ盤面の修正前後を比較し、結果画面内のフォント・ウェイト・文字倍率・余白を確認する。
日本語・数字・✓/✗・矢印、長い助言、設定キー名、狭幅、DPR／ズーム違い、フォント読込失敗、キーボードフォーカスを検証する。
評価図の順次消去・独自ぷよ素材・操作・採点・推薦・供給は維持する。
テーマ全体の見た目は代表画面を利用者へ提示して確認を得る。テスト成功だけで視覚品質完了としない。
