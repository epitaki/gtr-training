## 修正方針

1. Workerは異なる評価値を逆順に返して各要求と照合する。旧Workerの返答後に再試行が未完了であることを確認し、新Workerの異なる返答だけを採用させる。得点計算の正しさは別の採点回帰が担当する。
2. 操作案内はjsdomと実Reactで一度マウントし、設定保存だけで表示が変わることを確認する。保存失敗時の今回適用と購読解除も保護する。Reactの購読を差し替えるモック、取消コピー部、CSSクラスの期待値を撤去し、操作名と対応キーを確認する。
3. 恒真の位置assertを撤去し、残すテスト名は設定値の境界確認という範囲へ合わせる。実シーン全体の配置保証とは呼ばない。
4. 任意の`test:quick`と`test:slow`を追加する。slowは現行の長期プレイ回帰24件と公開環境の実Vite検証5件。quickはこの2ファイル以外。従来の`bun run test`は全件のままとし、完了前には全件を実行する。重い検証を削除したり成功件数を水増ししたりしない。
