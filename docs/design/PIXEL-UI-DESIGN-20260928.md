## Astra設計

背景#171426、盤面／入力#0c0a14、パネル#211d33、枠#6f648d、本文#f6f2ff、補足#c4bfd3。主操作#b5a8ff＋暗色文字、成功#91ecc2、注意#ffe99b、失敗#ff9aa5。直角2px枠・4pxの硬い影、余白4/8/12/16/24/32pxを基本とする。疑似bold・ぼかし・グラデーション・大きな丸角を整理する。本文16px、補足14px、見出し24/32px、得点32px、短い英字ラベルのみ12px。操作領域は原則44px以上、明瞭なfocus-visibleを備える。

DotGothic16 Regularをローカル配布し、React／Phaserのfamily順を共通化する。PhaserのTextStyleはnormal、resolution 2、役割別共通スタイルを基本とし、全canvasへのpixelatedやpixelArt指定は追加しない。

main.tsxでReact描画前にFontFace.loadを一度だけ待つ。期限2秒以内の成功のみdocument.fonts.addし、失敗・非対応・timeoutは同じ日本語fallbackで起動する。遅れて成功しても登録しない。同名のCSS @font-faceや無期限のfonts.ready待ちは使わない。初期待機はrole=statusで表示する。GameManagerの同期APIや開始timer／suspension契約には非同期処理を持ち込まない。

guided 900×800、score 640×800、セル48pxとScale.NONEを維持し、canvas領域だけ横スクロールを許す。toolbar・共有・設定はviewport内で折り返し、galleryは320pxで1列、GameControlsは小画面で3列×2行を許す。長いキー名・コメント・URLを折り返し、診断JSONは独立したスクロールを許す。結果画面・COACHは前要素のbottom＋gapで長文を配置し、説明の切捨てや文字縮小で重なりを隠さない。教材図だけ必要に応じ表示セルを36pxまで縮小可能。

アプリから未参照のTopMenu／GameLayout／GameBoardを新たなルートへ接続しない。既存pointer handlersを維持し、マウス割当の追加は行わない。既存PNG／atlas／manifestを再生成しない。
