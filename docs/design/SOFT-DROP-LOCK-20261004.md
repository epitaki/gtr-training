# 高速落下入力中の接地即確定

## 依頼と現在の動作

利用者指定: 高速落下(既定↓)を入力している時も、床や積みぷよでこれ以上下がれなくなったら即確定する。対象はガイドとスコアアタックの両モード。

従来は高速落下で一マス動かし、着地確定は800ms周期の自然落下に任せていた。このため接地から確定までの時間がばらつき、自由落下OFFでは高速落下だけでは確定しなかった。

## 実装方針と受入条件

- 一マスの高速落下と同時入力の左右移動・回転を適用した後、下がれない状態なら同フレームで既存の着地処理を一度開始する。
- 高速落下の押下イベントと保持状態の両方を確認する。150ms反復の間に自然落下で接地しても、そのフレームで確定する。
- 自由落下OFFでも高速落下による接地確定を行う。入力がない時の800ms周期、クイックドロップの即確定は維持する。
- 確定開始時に保持入力を解除待ちにし、次ツモへ持ち越さない。停止・連鎖・評価中は既存の入力制御を保つ。
- 連鎖物理は共通ChainSimulatorへ任せる。推薦・採点・乱数・ツモ生成・キー設定の変更は行わない。
