# 両モードの後続ツモを4色独立抽選へ揃える

開始日：2026-10-04。全工程GPT-6.1-sol。利用者の「同色2個が多い」「実践に合わせてランダム」「ガイドも同じ条件」の指定。

## 目的と受入条件

- ガイド練習とスコアアタックは、初期2組のみ既存の練習用制約を使い、3手目以降は赤・緑・青・黄から各ぷよを独立・等確率に抽選する。
- 後続1組の同色確率は理論25%、異色は75%。同色ツモを禁止したり、一定数に調整したりしない。連続した同色や短い期間での偏りも自然に起こりうる。
- スコアアタックの4手目以降で使用している初手生成のpair1を、ガイドと同じ `createRandomPair()` へ変更する。
- 初手2組の生成と3手目の独立抽選、両モードの開始／リセット条件を維持する。ガイドのseedと巻戻し・再現URLの乱数復元を変えない。
- 着地・連鎖途中や取消・無効配置では抽選せず、確定した有効手で1組だけ生成する。終端盤面では生成しない。表示復旧で再抽選しない。
- 採点・推薦・物理・10回セットの提出／保存／裏採点と点数一覧を変えない。同じ条件は抽選ルールの一致であり、別々のゲームが同じツモ列になることを意味しない。

1組16通りを固定入力で検査し、同色4／異色12を確認する。Sceneの供給テストで両モードが初手用生成を後続へ使わず、可視NEXTを順に進め、取消・終端・表示失敗で抽選が増えないことを確認する。固定seedの20万組で色別・同色／異色割合を比較し、実戦作品の配ぷよアルゴリズム全体を再現したとは主張しない。

型検査・全テスト・buildと実画面の両モード／10回制を確認する。開始時のScene、テスト、生成関数、仕様と記録を一時領域へ保存した。今回開始時との差を確認し、既存の未コミット変更を保護する。
