## 仕様と受入条件

- 旧設定1を撤去し、旧設定2を唯一の「設定1」とする。プロファイルの選択は設けない。
- 各操作の初期値は左端1キーだけ。←・→・Z・X・↓・↑・Esc、巻戻しA・評価Space・ガイドG・自由落下F・共有R。
- 各行の追加／削除、最大8キー、重複検出、保存／取消／初期化は維持する。追加キーは保存後も復元できる。
- マウスによる盤面移動・回転・落下とその設定・操作案内を撤去する。通常の画面ボタン、盤面へのフォーカス、タッチ用意味アクションは維持する。
- 保存形式はversion 1のキー保存領域を維持。旧設定2の全初期キーが完全一致する旧保存だけを新しい初期値へ移行する。カスタムキーはそのまま保持し、旧mouse属性は読み捨てる。新規保存にはmouseを含めず、defaultsRevision=2を付ける。新画面で全キーを旧初期値と同じに追加し直した場合も、その保存は再移行しない。
- 保存破損／アクセス失敗時は新設定1で復旧し、元データを保持して通知する。読込みだけでは保存データを書き換えない。
- 両モードと操作案内、追加キー・修飾キー・テンキー・状態ゲートを確認する。基本検証は型検査・全テスト・buildと実画面確認。
- 推薦・採点・供給・乱数・連鎖物理を変更しない。開始時入力ファイル／両Sceneを一時領域へコピーした。
