# 履歴のツモでガイド練習（2026-10-15）

状態: 反映・検証済み。優先度: 通常。

履歴の選択した回の詳細に「このツモで練習」を追加する。利用者回答により、保存された置き場所の再現ではなく、同じツモで通常のガイドの推薦に従って練習する仕様。空の盤面から、確定した手順に記録されている軸/子の色だけを同順で供給する。記録の末尾以降は既存のPuyoPairRandom/createRandomPairで生成し、NEXT/NEXT2にも同じ境界を使う。未配置の保存プレビューは記録済み手数に含めない。

手順未記録・空手順・不正な手順や最終盤面不一致では開始不可。履歴→各回の詳細→練習の導線だけを追加し、進行中のゲームを履歴閲覧だけで作り直さない。開始時は新しいガイド練習に切り替え、既存再現URLの検証モードを解除する。既存の保存ゲーム/お気に入り/APIは更新しない。

共通coreに色ペアの列と初期位置への変換を置き、scoreAttackで記録の検証/色抽出を行う。Sceneへ列を渡し、各ターンの絶対手数から必要な組を読む。独立した可変カーソルは持たず、既存の手順履歴/乱数状態の巻き戻しで、末尾前後の再操作も同じツモになる。新ゲーム/ゲームオーバー後は通常のランダム練習へ。通常練習の初手制約は維持するが、履歴開始時は記録の初手をそのまま使う。

手順途中の報告/再現URLにも任意の色ペア列を含め、続きを再現できるようにする。既存URLとの互換性を維持し、入力列の長さ/色を検証する。core/feedback/scoreAttackの依存方向を維持し、採点や推薦のルールを変えない。
