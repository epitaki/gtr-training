## 追加要件：矛盾する説明の確認

利用者の追加依頼：整理中に矛盾する記述があった場合、どちらが正しいかを資料や動画で調べる。
各時点の仕様変更・未実装案・不採用案は、現在の説明と区別して保持する。
実装の現状はソースと検証記録、ゲームのルール・技法は出典資料や確認できた動画内容を根拠に判定する。
具体的な矛盾候補、両記述、根拠、採否、修正先を調査記録へ残す。
動画の字幕・部分目視・全編視聴の範囲を分け、確認できない点を断定しない。
文書の訂正は根拠が確認できた範囲に限定し、ゲーム実装の変更へ範囲を広げない。
該当する誤りが見つかった場合、本文変更の制限に根拠付き訂正を追加する。
最終受入で具体的な矛盾候補が解決または当時の履歴として明確に区別されていることを確認する。

Astraは初手5分類・各20%という説明の誤りと、教材・配色・採点の古い現行説明を確認した。
親が教材・配ぷよの一次解析・制作者の説明を再取得し、実ゲームの配ぷよと本ツールの練習用抽選を区別した。
