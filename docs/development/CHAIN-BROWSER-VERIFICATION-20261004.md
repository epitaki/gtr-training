# 015 残検証の実施方法

2026-10-04。対象は既存の015-A/Cと親015。優先度・実装設計は維持し、全工程GPT-6.1-sol。

ガイドは既存5連鎖JSONを再現URLで開き、現在の入力設定で実操作する。連鎖開始を制御するため自由落下だけOFFにした検証用コピーを使う。原本・推薦・採点・供給は変更しない。
停止はEscape、取消はU。取消前後は共有JSONで盤面・CURRENT・NEXT/NEXT2・乱数・得点・履歴を照合する。

スコアアタックには固定局面を読み込むUIがないため、開発用の独立HTMLを `tests/browser/` に追加する。
本番エントリーから参照せず、Viteの開発サーバーでだけ開く。実際のPuyoGame・Phaser・素材・入力・ChainPlaybackを使い、検証窓口だけ固定局面をセットして観察結果をDOMへ表示する。
新しい物理実装・本番メニュー・推薦変更は追加しない。期待盤面は既存ChainSimulatorから算出し、単発と5連鎖、確定前の得点/NEXT不変、完了後の整合、繰返し後の残像と描画数を検査する。
実フレームで反復する負荷確認を行い、モックの生成数検査とは分ける。型検査と基本回帰も確認する。

操作ブラウザーでは別タブを開いても両方の `document.visibilityState` がvisibleだった。実タブ非表示の確認成功とは扱わず、実際にhiddenになった記録が得られるまで未確認を維持する。
検証ハーネスから擬似的なvisibilitychangeを発行しても、実際のタブ復帰の代替と記載しない。

006の共通完成表示の確認では、標準コア・土台3連鎖・既存研究JSONの横3の頭と評価ボタンを追加する。実際の結果画面の文字も観察欄へ表示する。結果表示後はSpaceで新ゲームへ戻してから次の固定局面をセットする。

015-Cの残るガイド長時間反復では、同じ開発用ページの `?mode=guide` に本物のGuidedPracticeSceneを起動する。固定局面をセットする際に教材役割・初期履歴・再現乱数を初期化し、実入力と実フレームで1/5連鎖を交互に120回再生する。連鎖途中はNEXT・得点・履歴・乱数を確定させず、完了後は共通物理・1回だけの履歴・次ツモ・実乱数を照合する。表示負荷の検査を分離するため、この反復では固定JSONどおりガイド推薦と自由落下をOFFにする。通常のガイド表示は既存の実画面確認を使う。期待値を満たすまで長時間負荷チェックを完了にしない。
