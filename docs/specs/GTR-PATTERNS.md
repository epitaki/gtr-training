# GTR（グレート田中連鎖）パターン定義

このドキュメントは、GTRトレーニングツールで使用するGTRパターンの定義と評価基準を説明します。

## 概要

**GTR（グレート田中連鎖）**は、ぷよぷよで広く使われる折り返し・連鎖モデルです。
元来の広い意味と、現代に多い「折り返し部分」の意味を区別するため、本ツールでは左側7ぷよの形を
**標準GTRコア**と呼びます。現行実装の対象は左折りの標準GTRコアであり、逆折りは難易度ではなく製品スコープ上の理由で対象外です。

## GTRの構造

**重要**: 本ツールがGTRとして検出する盤面には、標準GTRコアの折り返しが必要です。
ただし、歴史的な「元祖GTR」は折り返しだけでなく、カウンターや大きな連鎖尾を含む名称でした。

GTRは以下の2つの部分で構成されます：
1. **標準GTRコア**（本ツールでは必須）：1-3列目の特定の相対色形状
2. **接続・連鎖尾**：折り返しから右側へ消去順をつなぎ、連鎖を伸ばす部分

列番号だけで接続の良否は決まらない。同じ3列目への配置でも、色、周囲の連結、発火後の落下順によって
正解にも阻害にもなる。実装上の判断原則と調査元は [GTR-RESEARCH.md](../research/GTR-RESEARCH.md) を参照。

## 先折りGTR初手パターン（4分類）

学習時の認知負荷を下げるには、最初の2手（4つのぷよ）を同色関係で分類すると便利です。
以下の4型は代表的な練習用分類であり、後続ツモまで含めた唯一の最善手を意味しません。
以下の配置文は初手を学ぶための参考例で、現行の配置推薦が列や回転を固定する手順ではありません。
`AAAA` など全消しへ直結する初手を別ルートとして扱う記述も旧教材の分類であり、通常ゲームの初期生成や `GuideManager` の専用経路を示しません。本ツールの通常の初期2手生成ではAAAAを除外します。外部ゲームの全モードでの可否はここから判断せず、[現行のぷよ生成仕様](PUYO-GENERATION.md)を参照してください。

### 型1: AAAB（同色3+異色1）
- 初手を3列目にA上の縦置き、2手目を1-2列目に横置き
- 例: 赤赤赤緑 → 赤を3列目縦置き → 緑赤を1-2列目横置き

### 型2: ABAB / AABB（交互 or 対）
- 横置きで土台を形成。ABの位置は逆でもOK
- 比較的シンプルに折り返しへ移れる型

### 型3: ABAC（3色、Aが2個）
- Aを下にして1列目に縦置き、またはAを左にして2-3列目に横置き
- Cが不要色の場合は右側（4-6列目）に捨てる

### 型4: AABC（同色2+異色2）
- 初手の置き方を固定して配置
- BCが折り返しに使えない場合は右側に捨てる

**共通原則**: 折り返しに使えない色は、序盤は右端など折り返しを壊さない場所へ逃がす。
土台に使えるツモは土台を優先し、後半は完成済み部分の上も利用する。常に同じ列へ捨てる規則ではない。

## 対象GTRパターン

### 1. 標準GTRコア（本ツールの必須折り返し部分）

本ツールが左折り標準GTRを検出するときの必須形状です。GTR一般の全派生を定義するものではありません。

```
本プロジェクトのフィールド座標（列1-6、行1-13、13行目が最下段）:
1 2 3 4 5 6
A B _ _ _ _  ← 11行目：1列目A色、2列目B色
A A B _ _ _  ← 12行目：1-2列目A色、3列目B色
B B _ _ _ _  ← 13行目：1-2列目B色（最下段）
```

**特徴:**
- **必須形状**: この配置がなければ、本ツールでは左折り標準GTRコアとして検出しない
- **A色**: 11行目1列目 + 12行目1-2列目に配置（L字型）
- **B色**: 11行目2列目 + 12行目3列目 + 13行目1-2列目に配置（逆L字型）
- **折り返し**: 1列目でA色とB色が上下に折り返す形

**評価基準:**
- 基本スコア: 100点
- 必須列: 1列目、2列目、3列目
- 最低限必要な色数: 2色（A、B）

## 連鎖尾の学習用パターン

GTRの連鎖尾（3列目以降）を学ぶための参考配置です。
連鎖尾は3列目のB色が消えた後に連鎖が繋がるように配置します。

### 403パターン調査から分かる範囲

ぷよぷよキャンプの調査では、3-6列目・下4段・4連結だけに限定して403パターンを列挙し、
**バリエーション数**を「良型」の基準にした場合にY字が最多、次に横3、だぁ積みに似た形という結果でした。
これは対戦強度、火力、組みやすさを総合したランキングではありません。L字や階段を含む各例の良否は、
発火後の消去順、暴発、余りぷよ、後続ツモで個別に評価します。

※ 以下の小図は旧教材データにある学習用の参考配置です。現在COACHに表示する完成3図（Y字・座布団・L字）は `src/game/guide/GTRCompletionExamples.ts` に定義され、[現行の視覚ガイド](GTR-VISUAL-GUIDE.md)で説明しています。
※ 配置推薦ではY字・座布団・L字を同じセル進捗で比較し、型名による固定倍率は付けません。従来の `PlacementAdvisor.getCompletedTailShape`／`isAdaptiveTailComplete` の内部判定では、標準発火点からの連鎖をシミュレーションで確認します。これはプレイヤーが実際に発火したという意味ではなく、認識済みの頭伸ばしを除いた基礎盤面で確認する場合もあります。ガイドの尾完成表示は別の `isGuidedTailComplete` が実セルとキー待ち接続を確認し、[ゲームモード仕様](GAME-MODES.md)のチェックとして表示します。

### 1. Y字形

```
1 2 3 4 5 6
A B C _ _ _  ← 11行目
A A B C C _  ← 12行目
B B C D D _  ← 13行目（最下段。Dは支持ぷよ）
```

- **配置**: GTRの1-2列目 + Y字型接続3-5列目 + 4-5列目の支持色D
- **採点**: 型名だけの倍率は適用しない
- **特徴**: Bが消えた後、Cが落下して横につながり3連鎖目になる。DはCを浮かせず組むために必要

### 2. 座布団形

```
1 2 3 4 5 6
A B C _ _ _  ← 11行目
A A B C C C  ← 12行目
B B _ _ _ _  ← 13行目（最下段）
```

- **配置**: GTRの1-2列目 + 横方向連鎖尾3-6列目
- **採点**: 型名だけの倍率は適用しない
- **特徴**: 横に広がる安定した配置

### 3. L字形

```
1 2 3 4 5 6
A B C _ _    ← 11行目
A A B C _    ← 12行目
B B C C _    ← 13行目（最下段）
```

- **配置**: GTRの1-2列目 + L字型連鎖尾3-4列目
- **採点**: 型名だけの倍率は適用しない
- **特徴**: バランスの良い連鎖構築

### 4. 階段形

```
1 2 3 4 5 6
_ _ C _ _    ← 10行目
A B C _ _    ← 11行目
A A B C _    ← 12行目
B B D C _    ← 13行目（最下段）
```

- **配置**: GTRの1-2列目 + 階段状連鎖尾3-4列目
- **採点**: 型名だけの倍率は適用しない
- **特徴**: 連鎖数を伸ばしやすいが難易度高め

## GTR認識アルゴリズム

### 1. 基本パターン検出

システムは次の2段階で判定する：

1. `GTRDetector` は左下7セルの標準GTR折り返しを色A/Bの相対関係で検出する。
2. `PlacementAdvisor` は配置候補ごとに全列・全色の単ぷよ発火を試し、同時消去と重力を反復して最大連鎖を求める。

折り返し完成後のフェーズは、右側のぷよ個数ではなく、標準発火点からの連鎖数で決める。

### 2. 学習結果スコア（note.md由来の画面仕様）

以下は学習結果を表示するための仕様であり、連鎖尾の競技上の優劣や
`PlacementAdvisor` の候補評価を表すものではありません。現在の画面得点の配点は
[GTR-SCORING-SYSTEM.md](GTR-SCORING-SYSTEM.md) を参照してください。

```
連鎖尾の素点 = 連鎖数ボーナス + 最小完成ボーナス + あまりぷよ評価（最大85）
部分点 = 四捨五入(100 × ((基本形スコア / 100) × 0.5 + (連鎖尾の素点 / 85) × 0.5))
総合スコア = 安定した範囲内19個・事前消去なし・コア先頭2段・5連鎖全消しなら100、それ以外はmin(99, 部分点)
範囲は0〜100点。2026-09-24から満点の異なる項目を正規化して比較する。
```

#### 評価範囲
- 1-2列目: 11-13行目
- 3-6列目: 10-13行目

#### 評価タイミング
- Spaceキーを押したときに評価
- ガイドの結果表示中は停止し、Spaceで新しいゲーム、Escでメニューへ戻る

### 3. 詳細評価項目

#### GTR必須形状（100点）
- 基本GTR（11-13行目のみ）: 100点
- 拡張しても100点（上に置いただけの旧120点ボーナスは廃止）
- **折り返しがない場合: 0点（他の評価は行わない）**

#### 連鎖数評価（最大50点）
- 1連鎖あたり: 10点
- 最大評価: 5連鎖（50点）
- 評価範囲外を除いたコピーで、(1,10)に(1,11)と同じ色が来たときの連鎖数をカウント
- 範囲外のぷよは落下後も土台の連鎖・余りに含めない。実プレイの連鎖とは区別する

#### 最小完成ボーナス（15点、2026-09-27）
- 上記の最小完成条件を満たす場合15点、それ以外0点
- 4段目の位置だけによる15/10/5点は廃止し、6列目最高を必須にしない
- 平坦さへ固定加点せず、足場と限定した尾接続例を別に説明する
- [Y字3・8の比較と採点版](../design/GTR-SURFACE-QUALITY-20260927.md)を参照

#### あまりぷよ評価（最大20点）
- あまりぷよなし: 20点（最高評価）
- **複数色のあまりぷよ: 0点**（連結していても評価しない）
- 単一色3つ完全連結: 18点
- 余り1個: 18点
- 単一色2つ完全連結: 18点（3つ連結と同点。2026-09-24更新）
- 単一色だが分離: 5点

※ 4連結は消えるため、あまりぷよとして存在しない

## 対象外パターン

以下は現行の初心者向け製品スコープでは対象外です。競技上の価値や絶対的な難易度を否定するものではありません。

### ❌ 逆折りGTR
- 6列目から始まる逆方向の折り返し
- 左右反転の検出・ガイドをまだ実装していない

### ❌ 変則GTR
- 標準形から大きく外れた配置
- 基本習得を優先するため対象外

### ❌ 多重折り返し
- 複数箇所での折り返し
- 現行カリキュラムは第一折り返しまでを優先するため対象外

## 実装における注意点

### コード上の定義
- `GTRPatterns.ts` ファイルで定義
- パターンマッチングによる検出
- リアルタイム評価システム

### 座標系
- 列: 0-5（左から右、0-indexed）
- 行: 0-12（上から下、0-indexed）
- 最下段はインデックス12（13行×6列のフィールド）

### 色の表現
- パターン定義では A, B, C, D, E で表現
- 実際のゲームでは PuyoColor enum を使用
- null は空のマスを表す
