## 実装済みモード

### 1. 初心者用ガイド付きGTR練習

#### 特徴

- GTR初心者向けの学習特化モード
- 900×800pxのゲーム画面。右側に「完成例」とY字・座布団・L字のタブ、選んだ型の異なる3図を表示。2026-10-04の追加指定でCOACHの見出し・説明段落と完成図下の説明を削除した
- 段階的な学習支援システム
- 配置アドバイザーによるゴースト表示
- GTR完成を優先し、完成後は自動発火を勧めず発火点・連鎖尾を伸ばす

#### ガイドシステム

1. **最初の2手状態**
   - 最初の2組の同色関係と、見えているツモに応じた配置を案内
   - 初手分類だけで列や回転を固定せず、安全に折り返しを進める配置を優先

2. **基本形作成状態**
   - GTRの必須折り返し部分（1-3列目）の作り方
   - 上から11行目AB、12行目AAB、13行目BBの基本形を構築

3. **連鎖尾作成状態**
   - ツモと盤面に応じてY字・座布団・L字などの候補を比較し、採用した経路の型を案内
   - 尾完成は実セルと接続を確認する。元の本線へ戻るキー待ちを含むが、実発火済みとは扱わない

4. **完成確認・継続構築**
   - 基本形と尾の完成、土台5連鎖への到達を区別する。尾完成の案内だけで5連鎖や100点を保証しない
   - 土台5連鎖が成立したら、土台の接続を保つ頭・尾の伸ばしを案内
   - 安全に積める候補が見つからなければ、ゴーストを消す。判定と評価・巻き戻し操作は維持し、右パネルの説明段落は追加指定で表示しない

#### 配置アドバイザー

- 現盤面とCURRENT・NEXT・NEXT2の最大3組から配置を推薦。未知の将来ツモは参照しない
- `PlacementAdvisor` の構築探索を `ContinuousAdvisor` が非発火・完成優先の練習方針へ接続する
- 折り返し保護、骨格の進捗、安全性、相方回収、完成後の接続などを比較。単純な5項目の合計だけで最終順位を決めるものではない
- 基本形完成後・尾未完成の候補が既存評価で完全同点の場合は、同じ尾型・進捗・余剰数・完成段階で次の配色の選択肢が多い手を優先する
- **ゴースト表示**: 推薦位置に半透明ぷよ（パルスアニメーション付き）
- **配置の案内**: ゲーム盤面のガイドは1案のみ。2026-10-04の利用者の最新指定で、盤面下の3候補比較欄と追加図は撤去した。推薦の順序・採点・供給は維持する。[変更記録](../reviews/PLACEMENT-CANDIDATES-CHECK-20261004.md)。
- 初期設定では **Gキー**でON/OFF切替可能。キー設定から変更できる

#### ガイド表示仕様

- **配置**: ゲームフィールド右側
- **サイズ**: 幅380px・高さ684px。見出し「完成例」、3つのタブ、6列×4段・1マス36pxの3図を縦に表示する
- **完成例**: 選択した型の既存ギャラリー先頭3例を表示。Y字ならY字3図、座布団なら座布団3図、L字ならL字3図。配色だけの複製は使わない。自動では推薦の型、ガイドOFFや型不明ならY字を表示する
- **手動閲覧**: タブで型を選び、その型の3図へ切り替える。「ガイドに合わせる」で自動へ戻る。閲覧で推薦・盤面・供給・履歴は変更しない
- **表示の区別**: タブの枠と背景で選択中の型を示し、自動追随時は「ガイドに合わせる」も強調する。ガイドON/OFFはNEXT横の状態表示を維持。旧「今回の案内」「教材を閲覧中」等の文章は撤去した。完成例は教材であり、現在のツモでの到達や100点を保証しない
- **配色**: 折り返しの配色を参考に、A/B/C/Dへ異なる4色を割り当てる。A→赤などの固定対応ではない
- **操作制限**: 報告・結果・再現確認中、ゲームオーバー、表示停止等では教材切替を受け付けない
- **背景・素材**: ダーク背景と紫系枠線、実ゲームと同じ接続ドット絵
- **盤面下**: 「GTR FOUNDATION」と「操作キーは画面下の一覧を確認」を撤去。DOMのキー操作一覧も2026-10-10に撤去。キー設定とタッチ操作・停止時のキー案内を維持する。終了条件時のオーバーレイ/操作待ちは設けず、新ゲームへ自動移行する

完成図と操作例は [GTR視覚的ガイド](GTR-VISUAL-GUIDE.md) を参照。

#### 学習支援機能
- 初期「設定1」：Aで1手巻戻し、SpaceでGTR評価、Gでガイド、Fで自由落下、Rで共有
- Escでポーズ・再開。終了は画面の明示ボタン。P互換割当はない
- 結果画面では新しく押したSpaceで新ゲーム、Escで終了。評価Spaceを押し続けたまま結果画面に移っても再開せず、一度離す必要がある
- 基本操作は左右が←・→、回転がZ・X、高速落下が↓、クイックドロップが↑。各操作の初期値は1キーだけ
- 旧設定2を唯一の「設定1」とした。キー設定画面で追加／削除、保存、取消、「初期設定に戻す」ができる。各操作は最大8キー、重複や未許可キーは保存できない。Ctrl/Shiftを追加した場合は左右共通、テンキーを追加した場合はNumLockに関係なく操作できる

#### 評価システム
詳細なチェック形式の評価結果（成功✓/失敗✗の両方を表示）：
- ✓/✗ 折り返し（必須パターンの有無）
- ✓/✗ 連鎖尾基本形（Y字・座布団・L字のいずれか。ガイド側の `isGuidedTailComplete` による別判定）
- ✓/✗ 3連鎖 / 4連鎖 / 5連鎖
- ✓/✗ 最小土台の完成（範囲内19個、コア2段を含む5連鎖・余りなし。安定性・事前消去なしも確認）
- ✓/✗ 余りなし・1個・同色連結（範囲外を先に除いた土台の仮想発火後。余りなし ＞ 1個 ＝ 同色連結）

連鎖尾基本形のチェックはキー待ちの接続を含むため、実発火済み、土台内5連鎖到達、100点を単独では保証しない。形状の教材・推薦と共通採点の結果を分けて読む。

7連鎖は達成チェック・追加目標にしない。連鎖数による数値加点は従来から5連鎖が上限。
実際に起きた連鎖数の表示・記録は切り詰めない。4段目の必要性を個別に判断する新しい自動評価は未実装。
総合スコアは各項目の満点を揃えた0〜100点。利用者の3つの理想形はいずれも100点。
満点には安定した範囲内19個・事前消去なし・コア先頭2段・ちょうど5連鎖・全消しが必要。
4段目の特定列を必須としない。右端の高さだけで加点せず、一覧のY字3・8も同じ最小完成として扱う。
範囲は1・2列目の下3段、3〜6列目の下4段。範囲外の相方や伸ばしがあっても土台100点になりうる。
範囲内の余分なぷよなどで条件を外れる場合は最大99点。上へ置くだけの拡張ボーナスは廃止した。
実プレイの全盤面連鎖・残数と、範囲外を除去してから計算する土台の評価を混同しない。
配点は [GTR評価システム](GTR-SCORING-SYSTEM.md) を参照。

#### 結果画面の連鎖プレビュー

- GTR評価範囲の図は1マス36px、6列×4段（216×144px）。以前の縦横2倍で表示する。
- 評価範囲外を先に除き、発火色と同色の1個を仮置きしたコピーで消去順を表示する。仮置きの1個は黄色い枠で区別する。
- 結果表示時に1回自動再生し、消えるぷよだけを順番にフェードする。落下は即時切替で、落下モーションは付けない。
- 「もう一度」で同じ連鎖を再生できる。発火色や消える組がないときは理由を表示する。
- 共有画面・再現確認中・非表示中は停止。Spaceで新ゲーム、Escでメニューへ戻る操作は維持する。
- これは土台の仮想発火の説明であり、元の盤面・得点・ツモ・推薦を変更しない。基本形が不成立の場合も仮想消去が起こりうるが、採点の連鎖数を上書きしない。

設計・検証は [結果画面の拡大・土台連鎖プレビュー](../design/RESULT-CHAIN-PREVIEW.md) を参照。

### 2. GTRスコアアタック

#### 特徴
- 10回1セット、各回のGTR土台スコア0〜100点を合計する。最終点数は最大1,000点（640×800pxのゲーム画面）
- 提出した盤面を固定し、Web Workerで既存の採点と完成状態の説明を計算する
- 各回の詳細表示を挟まず次の盤面へ進み、最後にまとめて振り返る

#### ゲームプレイ
- 通常のぷよぷよルール
- 2手目組み合わせ制約適用
- ネクスト・ネクネクスト表示（縦型ボックス）
- 壁キック機能

#### 操作
- ガイドと同じ設定1の初期設定を使う。Spaceで採点して次へ、Escでポーズ。追加した評価キーも同じ動作。スコア側のF/自由落下切替は撤去し、自然落下は常時ON（800ms周期）。キー設定にも切替項目を表示しない。ガイド側の設定/保存キーは維持
- 1〜9回目は採点を待たず新しい盤面へ移る。10回目は11回目を生成せず、合計と10個のGTR図を並べた一覧へ切り替える。各図の下に点数を表示する
- 図を選ぶと総合点・正の加点項目と点数、ガイドと同じ土台の消去順を開く。項目名は「基本形」、保存した数に応じた「3連鎖」「あまり0個」「あまり1個」等、「最小土台」。内訳の整数合計は総合点と一致し、0点の項目や完成/未完成は表示しない。旧/未知の採点版などで内訳を確定できない場合は保存総合点だけを示す。右の全体図・助言題名・指定された説明文と連鎖/余りの重複表示は追加指定で撤去した
- 仮想の発火ぷよ1個を明るい枠で区別し、評価範囲だけを再生する。「戻る」、Esc、背景クリックで同じ一覧へ戻る。「もう一度」で新セット、終了でホームへ。再生の状態通知は読み上げ用に維持する
- 詳細の「手順を見る」から、確定した組ごとの色・配置・実際の消去と落下を再現する。前の手・次の手と進行表示を使う。開閉ボタンの手数表記・「提出時まで」ボタン・下側の説明文は追加指定で撤去した。入力キーの押下時間の録画ではない
- 押し続けた評価キーは重複提出しない。ポーズ・連鎖・設定・完成形一覧・アカウント表示中は提出しない。終了条件の盤面は連鎖確定後に保持して停止し、フィールド内にGameOverを表示する。自動提出は行わず、新しく押した評価キーで採点して次の回へ進む。10回目も明示評価で結果画面へ移る
- 未完成や0点も1回に数える。通常の消去得点・構築中のGTR検出累積点・所要時間は最終点数へ加算しない
- 採点中は一覧外に状態を表示する。失敗時は0点に置き換えず、保存盤面から「採点をやり直す」で再試行できる
- クイックドロップは現在の組を支持位置まで下げ、通常の着地経路で確定する。自然落下の周期を待たず実行可能

両モード共通の落下・確定規則：高速落下(既定↓)の押下または保持中は、左右移動・回転・落下を適用した結果、床や積みぷよでこれ以上下がれなくなったフレームに着地処理を開始する。150msの高速落下反復待ち中も接地を確認し、ガイドで自由落下OFFにしていても確定する。確定時の保持入力は解除待ちとなり、次ツモへ持ち越さない。高速落下を入力していない時は従来の800ms周期で自然落下・着地判定を行い、ガイドの自由落下OFFでは接地だけで自動確定しない。スコアは常時ONのため800ms周期で自然落下・着地判定を継続する。左右移動・回転による接地猶予のリセットはない。[設計と受入条件](../design/SOFT-DROP-LOCK-20261004.md)。
- 進行中の回数をゲーム内上部に1箇所表示。React操作行の回数は撤去。NEXT下はTOTAL SCORE見出しと提出済み回のGTR評価合計を表示し、未確定の回が残る間は—、初期/新セットは0。RESULT・Spaceで次へ・1回100点満点・自由落下状態の表示は撤去。完成形一覧の一時閲覧ではセットを保持し、モード退出で採点処理を破棄する

両モードの評価範囲は1〜2列下3段・3〜6列下4段（22マス）。背景色は盤面全体で統一し、範囲外と接する段差境界のみ幅1pxの点線（4px線/4px間隔）を引く。外枠や対象セル内部の枠は追加しない。採点・推薦・物理・ツモの条件は変えない。

スコアアタックの保存単位はGTR10回の1ゲーム。全10回の採点成功後、最初の提出時と完了時のログインユーザーが一致する場合だけ本人のSupabaseへ保存する。ゲストの結果は自動保存しない。最大100ゲーム、満杯時はお気に入りを除いて作成日時の古い順に入れ替える。全100件がお気に入りの場合は保存を止め、解除と再試行を案内する。同じゲームの通信再試行では再削除しない。

左メニューの「履歴」から自分の保存ゲーム・お気に入り・各回の評価と手順を開ける。「保存したゲーム」ボタンは撤去済み。最終盤面は39文字、確定した組は1手3文字で保存し、毎手の盤面・画像・分析文章を重複保存しない。点数と採点版は保存し、説明は閲覧時に生成する。ローカルDBとクラウドDBで受入済み。クラウドのGoogle/GitHub OAuthと本人プロフィール・画像変更も設定・検証済み。

10回制の [元設計](../design/SCORE-ATTACK-TEN-ROUNDS-20261004.md) と、現在の [結果図・手順・保存設計](../design/SCORE-ATTACK-HISTORY-20261004.md)／[受入記録](../reviews/SCORE-ATTACK-HISTORY-CHECK-20261004.md) を参照。

キー設定は両モードで共通の専用保存領域を使う。読取りに失敗した場合は設定1の初期設定をその回に使い、元の保存データは保持して通知する。書込みに失敗した場合は今回だけ適用したことを通知する。
マウスによる盤面移動・回転・落下とその設定は利用者指定で撤去した。通常の画面ボタンと盤面へのフォーカス、タッチ用ボタンは維持する。[現在の操作設計](../design/SINGLE-KEY-CONFIG-20261004.md)。
version 1の旧設定2の全初期キーが完全一致する旧保存だけを1キーへ移行し、カスタム割当と追加キーは保持する。旧mouse属性は無視する。新規保存にはdefaultsRevision=2を付け、追加キーを旧初期値と同じにしても再移行しない。読込み時に保存データを上書きしない。

## 完成形一覧（閲覧機能）

Y字・座布団・L字を各10例収録する。カードを選ぶと拡大モーダルで、発火用の仮想1個を足した5連鎖の消去順を確認できる。
落下は瞬間切替。完成形例の連鎖再生完了後は、ぷよと仮想発火枠のある初期表示へ戻して停止する。「もう一度再生」、閉じるボタン、Esc、背景クリックに対応する。
動きを減らす設定では自動再生せず、手動で開始する。

30例はいずれも低い19個の5連鎖土台。各連鎖で消える元のマスと順番で重複を除外し、配色だけで別例に数えない。
4段目の置き方が異なる例も含め、共通採点器で検算した30例はいずれも最小完成100点。画面の土台評価・列高・段差・足場・尾接続例の説明は2026-10-11に撤去し、図と1-1〜3-10の例番号を表示する。
教材であり、現在のツモで作れる保証や、実ゲームの100点達成記録ではない。
一覧を開いた間はゲームを保持して停止し、戻ると同じ盤面から続ける。別の練習モードやホームへ切り替えた場合は従来どおり。
詳しい契約と検証状況は [完成形ギャラリー](../design/GTR-COMPLETION-GALLERY.md) を参照。

## 共通機能

### 基本操作
- 初期「設定1」では、**←・→**で左右移動、**↓**で高速落下、**Z・X**で左右回転、**↑**でクイックドロップ
- **Esc**はプレイ中・連鎖中のポーズ／再開。終了は画面の明示ボタンから行う
- ガイド練習の結果画面では新しく押した**Space**で新ゲーム、**Esc**で退出。スコアアタックは上記の10回一覧と明示ボタンを使う。ゲームオーバー・表示障害時のEsc退出も維持する
- 設定画面でキーを変更した場合、実際の操作は保存した割当に従う。画面内の操作案内もそれに追随する
- **Tab / Shift+Tab** は設定・終了などの画面ボタンへ移動するために予約し、ゲーム操作には割り当てない

通常回転と壁キックができず、縦ぷよの軸の左右が壁または積みぷよで塞がれている場合は、
**割当済みの左回転／右回転操作を1回押すと同じ2マス内で上下を交換**する。両ゲームモード共通。
軸・子の色は保持して座標と向きを更新する。せり上がりや、横向きから床を抜ける動きは追加しない。

### ビジュアルシステム

- **PuyoRenderer**: 独自ドット絵アトラスとフレームの登録

### GTR評価システム
- 両モードで共通の完成表示モデルを使い、標準コア完成・土台5連鎖完成・現在ペアの発火可能/将来色待ちを分ける。発火可能は未発火。[確認結果](../reviews/GTR-ANALYSIS-CHECK-20261004.md)
- GTRScoringConfig.tsによる設定値管理
- 必須折り返しパターン検出
- 評価範囲内の土台連鎖、安定した最小19個の完成条件を採点
- あまりぷよ評価（余りなし ＞ 1個 ＝ 同色連結）

共通採点器 `src/game/gtr/GTRPatterns.ts` の `chainTailType` は現在 `undefined` で、形状名を確定しない。Y字・座布団・L字の尾候補評価と `isGuidedTailComplete` はガイド固有の別判定として使い、共通採点の5連鎖や100点と混同しない。[採点仕様](GTR-SCORING-SYSTEM.md)と[視覚ガイド](GTR-VISUAL-GUIDE.md)を参照。

### 2手目組み合わせ制約

- 開始時の2手はAAAB、ABAB（AABBを含む）、ABAC、AABCの4分類を各25%の選択幅で生成する。AAAAは本ツールの練習目的で除外
- 初期2手に4色すべてが揃うことはない。ガイド・スコアアタックとも3手目以降は各ぷよを4色から独立・等確率に抽選する。同色2個は理論25%、異色は75%。後続の任意の隣接2手に3色制約を保証しない
- 4色固定（赤・緑・青・黄）

抽選幅と各モードの供給経路は[ぷよ生成仕様](PUYO-GENERATION.md)を参照。外部ゲームの全モードでAAAAが出ないという意味ではない。
