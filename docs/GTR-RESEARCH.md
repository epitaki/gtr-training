# GTR調査メモと実装原則

最終更新: 2026-09-03

この文書は、配置ガイドを修正するために外部資料と実装を照合した結果をまとめる。
本ツールは左折りの標準GTRを初心者向けに扱う。

## 調査で確認できたこと

### 1. GTRは「特定の列へ置く手順」ではなく、折り返しの構造

公式資料では、端の2〜3段目に同色のL字を作り、別色で囲って横・上へ伸ばす形として説明されている。
したがって、3列目など一つの列を無条件に高評価する実装は不適切である。列は役割を持つが、良否は色と消去順で変わる。

- [日本eスポーツ連合・セガ「ぷよぷよeスポーツ」解説リーフレット](https://info-esports.sega.jp/wp-content/uploads/2024/07/puyopuyo_esports_leaflet.pdf)

### 2. 最初の2手はツモの色関係で分岐する

代表的な分類は `AABB / ABAB`、`AAAB`、`ABAC`、`AABC`。同じ座標列を毎回なぞるのではなく、
ツモ型に応じた初手定型を使い分ける必要がある。特にABACは同色部分を横につなぐこと、
AABCは2個のAをGTR下部へ使うことが初心者向けの基本として説明されている。

- [GTRの初手手順まとめ](https://puyo-euphonic.com/gtr-first-procedure)
- [先折りGTRの初手2手を完全固定する](https://puyo-camp.jp/posts/125661)

### 3. 初心者練習は完成形を一度に要求しない

折り返しだけの3連鎖、土台を足した5連鎖、折り返し上部を伸ばす、最後に7連鎖という段階練習が有効。
また、折り返しに使いにくい色は序盤では右端へ逃がし、土台に使えるツモなら土台を優先する。

- [初心者向けGTRの組み方・練習手順](https://piropuyo.com/puyopuyo-gtr/)

### 4. 連鎖尾はY字接続が初心者向きだが、形の名前だけでは判定できない

Y字接続は横方向にもつながり、後続の色に対応しやすい。一方で、列の高さが似ているだけではY字とはいえない。
実際に発火したときの消去順と、連鎖に参加するぷよをシミュレーションする必要がある。

- [GTR初心者向け解説PDF](https://www.chueq.com/asset/puyo/GTR.pdf)

## 配置ガイドへの反映

`PlacementAdvisor` は次の順で候補を評価する。

1. 左下のL字＋フタ色からなる標準GTR折り返しを壊さない。
2. 現在ツモの全合法配置を列挙する。
3. 各配置で起きる消去を先に解決してから、全6列・全4色の仮想単ぷよトリガーを試す。
4. 4個以上の同色連結を同時消去し、重力を適用して、連鎖が止まるまで繰り返す。
5. 最大連鎖数と連鎖参加ぷよ数が大きい配置を優先する。
6. 同点付近では、暴発、過度な高さ、孤立、折り返し破壊を減点する。

仮想単ぷよは実際の1手ではなく、盤面の接続可能性を比較する探索プローブである。
`COMPLETION` はこの任意色探索では決めず、標準GTRの発火点から3連鎖以上になることを条件とする。

重要なのは、`3列目だから正解` や `右側に6個あるから完成` とは判定しないこと。
3列目が最善になる盤面はあるが、それはシミュレーション結果として選ばれる。

### 初心者向けY字トレーニング

ガイドモードでは最初の2手からA/B色を一度だけ決め、途中で変更しない。
最小3連鎖ではC=A、支持色D=Bを使い、次の物理配置を目標にする。

```text
A B C _ _
A A B C C
B B C D D
```

- A: 1連鎖目
- B: 折り返して消える2連鎖目
- C: Bの消去後に落下・接続するY字の3連鎖目
- D: 4・5列目のCを浮かせず置く支持ぷよ

Y字セルと1列目上の発火口は予約領域とし、誤色を置く候補を実質的に除外する。
不足が1セルだけの場合は同色ペアを生成せず、CにはD、AにはBを相方として暴発を避ける。

## 現在の制約

- 折り返し検出は左折り標準GTRの7セル形を対象にしている。
- 配置評価の発火探索は仮想単ぷよによる接続可能性の比較であり、そのまま実ゲームで可能な手を表さない。
- 実際のNEXTがある場合は別途1手先読みも加える。
- 逆折り、雪崩・だぁ積み等の高度な派生を同じ基準で完全評価するものではない。

## 回帰テスト

- 配置比較用の仮想発火が全列で探索されること。
- 現在手の消去後に盤面を安定化してから、次の仮想発火を探索すること。
- 折り返し後に右側のぷよが一定数あるだけでは完成扱いにしないこと。
- テスト、型チェック、プロダクションビルドをBunで通すこと。

## シミュレーション指標

旧シミュレーションの90%超は「折り返し7セルの完成率」であり、Y字や3連鎖の完成率ではなかった。
この数値はGTR完成率として使用しない。

`bun run measure:guided` は実ゲームと同じ初手2手、NEXT、NEXTNEXT、ガイド色生成を再現し、
各着地後の消去と重力も解決する。折り返し・明示Y字・3連鎖に加え、
同一盤面で明示Y字と3連鎖が成立した「ガイド目標」を集計する。

2026-09-03時点、15手・200局の実測:

- 折り返し: 200/200（100.0%）
- 明示Y字: 196/200（98.0%）
- 3連鎖: 196/200（98.0%）
- ガイド目標（明示Y字かつ3連鎖）: 196/200（98.0%）
- ガイド目標完成まで平均9.1手

乱数試行なので、継続的な保証値ではなく回帰確認値として扱う。
