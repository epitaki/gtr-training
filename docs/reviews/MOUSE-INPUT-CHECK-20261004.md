## 実装と確認

- 画像の左右移動、右クリック回転、左クリックのクイックドロップ、左長押しの高速落下、Escのポーズを設定から使える。
- 短押しと250ms以上の長押しを分け、長押し後にクイックドロップしない。クリックと長押し・中ボタン・併用も個別設定できる。
- canvasの盤面内だけで取得する。教材ボタン、NEXT、画面外、設定・報告、入力欄、タッチにはゲーム操作を追加しない。
- inputの共通アクションと状態ゲートを使用。保持元を分離し、canvas外の解除、pointercancel、blur、hidden、設定変更と状態遷移で保留を取消する。
- version 1のキーボード保存に任意のmouse項目を追加。旧保存の割当を自動変更せず、不正mouseだけなら有効なキーボード設定は保持して通知する。

マウス設定の保存、個別変更の取消、モード間共有、再読込後の復元、Escのポーズ表示を確認。実ブラウザの長押し時間の測定は行っていない。
長押し開始と反復、解除後の非落下、停止・結果・hidden等の操作遮断、押下元分離、表示倍率補正、教材領域の除外は純粋入力と実DOMイベント経路の自動回帰で確認した。
