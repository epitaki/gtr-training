# NEXT・NEXT2表示改善（2026-10-10）

実装・PC/360pxのブラウザ表示・関連回帰・型検査・全体テスト・buildを確認済み。依頼範囲の受入完了。

## 変更とレビュー

利用者のぷよスポ画像を参考に、NEXTを左上、NEXT2を右下へ32pxずらし、1つの段差付き枠へまとめた。両方とも盤面と同じ48×48px、通常idle素材24pxを2倍表示。NEXT2の薄い表示はやめ、4個すべてalpha=1に揃えた。サブ上・メイン下の色と順番を維持する。

共通rendering/NextPreviewが幅120px・高さ288pxの枠/ラベル/組ぷよを描き、両Sceneが既存の表示破棄・更新を所有する。下部の状態/情報パネルは枠の下へ移した。ガイド完成例には24pxの間隔があり、ラベル/状態表示とぷよを重ねない。盤面・ツモ状態・乱数・物理・推薦・採点・履歴のロジックは変更していない。

開始時コピーとの差は next-preview-20261010/task-changes.patch。旧サイズを期待する既存回帰を、両組48px・通常素材・色順序・枠内収まり・表示更新の非破壊性の確認へ更新した。
